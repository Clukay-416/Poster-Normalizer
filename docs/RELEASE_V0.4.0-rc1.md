# V0.4.0 RC1 完整离线依赖包

这是完整功能候选版：应用与三套 AI 运行环境一起分发，模型权重独立下载和迁移。**已通过 Windows 应用与浏览器测试、AI 环境导入检查；尚未在 RTX 4090 上验证真实权重推理、显存峰值与重绘画质。** RC1 不代表画质验收完成。

## 下载与启动

1. 将发布页全部 `Windows_Full.zip.001`、`.002` 等分卷，以及 `full-manifest.json`、`Extract-Full-Package.cmd`、`Extract-Full-Package.ps1` 下载到同一个文件夹。不要用 GitHub 的 Source code ZIP 代替安装包。
2. 双击 `Extract-Full-Package.cmd`，它校验每卷 SHA256、合并并解压。首次解压会额外保留合并 ZIP，确认成功后可自行删除该 ZIP 和分卷。
3. 进入解压文件夹，双击 `start.cmd`。首次启动自动使用随包 Python、VC++ 安装程序和 AI 运行环境，不从 GitHub 或 pip 下载。VC++ 安装可能请求 Windows 管理员授权。NVIDIA 驱动仍需机器预装。
4. 浏览器进入“模型中心”，在笔记本选择独立模型目录并下载需要的模型。全量锁定模型约 25.25 GB；该数字不包含运行环境。下载、校验完成后关闭程序，复制整个模型目录到 4090 机器，在其模型中心选择对应目录并重新校验。
5. 安装文件夹可整体拷贝；外置模型目录需要另外拷贝并重新指定。升级请解压到新目录，先备份并迁移 `data`；不要用新文件覆盖正在运行的旧安装。旧版本不要再打开新版写入的数据。

建议为下载、解压、运行环境安装及全量模型预留至少 100 GB 空间，这是安装余量建议，并非实测常驻占用。首次依赖解包可能耗时较长，控制台会显示进度。

## 本版功能

- 修复复核确认按钮持续等待、单击预览误判修改；显示阻止确认的具体原因，支持放弃草稿和版本冲突保护。
- 独立的预览缩放、平移、适应窗口与 100%；输出区提供整图缩放、偏移、比例裁切。只改构图时不必重新运行修补模型。
- 单项/批量删除、回收站、恢复、彻底删除；运行中任务在安全边界进入回收站。
- SDXL Inpainting、PowerPaint V2、SAM2.1、GroundingDINO、AnyText2 适配，保留 OCR、LaMa；标题边缘精修、独立标题编辑与透明 PNG 保存。
- 修补支持保护区、上下文边距、蒙版扩张/羽化、多候选、种子和候选版本保留。AnyText2 结果不保证透明，仍需在标题工作室清理背景。
- 素材 API 不可达时可手动上传；本地编辑、已安装模型推理不依赖素材网站。艺术字入口与网站链接在素材检索/标题工作室。
- AI 环境隔离与 GPU 请求串行；每次运行完退出子进程释放资源。代价是下次推理需要重新加载模型。PR/ME 优先模式阻止新推理，不会强制中断正在运行的推理。

## 4090 验收

在模型中心逐项检查路径、文件校验与运行环境状态。依赖导入成功并不表示模型推理已成功。生成类自检与 AnyText2 生成需要手动确认；请先用一张非关键海报测试，再进行批处理。遇到失败可导出诊断信息，AI 子进程日志保存在 `data/ai_logs`。暂未附原截图同图画质对比，不能保证标题一次抠净或复杂天空一次修补成功。

应用和模型分别遵守自身许可，具体见包内 `THIRD_PARTY_NOTICES.md` 与模型中心。此包不含用户图片、个人 API 凭据和模型权重。
