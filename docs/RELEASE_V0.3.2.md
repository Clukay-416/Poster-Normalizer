# V0.3.2 · 标题独立编辑第一阶段

## 已实现

- 修复 Canvas RGBA 蒙版擦除：前后端均应用透明度，兼容旧灰度蒙版。
- 独立标题工作室：无需网络/模型；导入 PNG、WebP、JPEG，透明棋盘格、100/200/400% 查看、擦除、恢复导入像素、点选删除连通杂块、撤销重做、裁切透明边、下载透明 PNG。
- 标题库按新版本保存 logo.png、original.png、alpha.png 和元数据，保留前一版本链接；登录工作组共享访问。
- 从海报编辑器进入标题工作室时保存修补草稿；返回后应用精修标题并保留蒙版。提交新版任务后旧草稿失效。
- 名称检索增加海报、透明标题（TMDB logos）、背景图分类。Fanart 支持手填电影 TMDB ID 或电视剧 TVDB ID 查询标题。
- 增加 TMDB/Fanart 官网链接、独立 PNG 下载和离线上传入口。后台 API 无网络时仍可离线编辑。

## 使用方法

1. 在原海报编辑页提取标题或上传 Logo，点击“独立精修标题”。
2. 在棋盘格上擦除杂质，或选择“点选删除连通色块”。误删可撤销或恢复导入像素。
3. “另存新版本到标题库”不需要修补背景；“下载透明 PNG”可直接拷到另一电脑。
4. “保存并应用到原海报任务”返回排版。最后仍需提交修补、人工确认后导出。
5. 查询艺术字：素材页选“透明标题 / Logo”，填写影视名。API 不通时从官网手动下载，再在标题工作室上传。

## 明确未完成

- 本版没有新增大面积天空重绘引擎，仍使用 OpenCV / 已配置的 LaMa。
- SAM2 自动分割、matting 去背景色、羽化/扩缩蒙版、旋转等属于下一阶段，不能把本次人工精修描述为 AI 抠图。
- 没有自动按名称查询 Fanart 的 TVDB ID 映射；该入口明确要求手填正确来源 ID。
- 背景分类不代表保证无字。当前搜索每来源最多 8 个作品、每作品最多 20 张图片、总返回最多 120 张，不是全部结果分页。
- 原始标题已丢失的笔画不能通过“恢复”凭空重建；连通删除可能同时删除相连笔画，须人工核对。
- 新版大模型环境和模型离线包尚未交付，应用 ZIP 不包含模型。

## 模型路线核实

之前“BrushNet + SDXL 可以直接作为首选组合”的说法需要纠正。上游 README 仍将新版 SDXL checkpoint 列为 TODO，并提示早期 SDXL checkpoint 训练不足。先对比官方支持的 BrushNet 组合与独立 SDXL Inpainting，再锁定可复现的依赖、权重版本与许可，不把未经验证的组合打包为可用功能。

- https://github.com/TencentARC/BrushNet
- https://huggingface.co/diffusers/stable-diffusion-xl-1.0-inpainting-0.1
- https://github.com/facebookresearch/sam2

高质量推理需独立 Python/CUDA 工作进程，离线加载、无运行时自动下载、只回填授权蒙版范围；4090 实机显存、耗时、PR/ME 抢占与雷暴样片效果仍需验证。本次未生成或重绘用户图片。

## 升级

退出旧版 CMD 并备份旧安装目录。建议将新版解压到新目录测试；模型保持原独立目录。需要继续旧任务时，先关闭两套程序再复制旧 data 到新版安装根目录，不要在程序运行时复制数据库。标题库位于 data/titles，应与 data 一起备份。请勿删除旧安装目录，确认迁移成功后再自行归档。
