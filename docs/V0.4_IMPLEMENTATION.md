# V0.4 完整版开发记录

此分支仍在开发和验证，不是完成的正式发布。

范围：复核状态与幂等确认；独立查看缩放、输出背景缩放/裁切；回收站及恢复；本地 CUDA worker；SAM 2.1、GroundingDINO、SDXL Inpainting、PowerPaint V2、AnyText2；透明边缘精修；候选选择与历史版本；离线依赖包。

应用目录 `app`、轻量运行环境 `runtime`、三套 AI 环境 `runtime-ai`、任务 `data`、可迁移模型 `models` 独立。目标电脑安装 AI 运行包时仅校验、解包，不访问 GitHub/PyPI/Hugging Face。模型中心下载和校验模型；完整复制模型目录保留清单和内容校验值。

三个运行环境分别固定依赖：modern（SAM/检测/SDXL/抠图边缘），powerpaint，anytext。运行环境构建包含真实上游模块导入检查；这不等同于 CUDA 推理或海报质量验收。

任务列表和 API 的编辑仍是工作组共享。永久删除限管理员，运行中任务先等待安全边界，禁止提前清理正在写入的目录。回收站不会删除外部导入源文件或模型。

AI 推理使用短生命周期进程，文件传递，禁止外网 socket 连接。每次完整请求后释放显存；会有重新加载模型的延迟。PR/ME 优先时不启动新 CUDA 请求，已在运行的请求完成后释放显存。无付费服务兜底。

必须完成的验证：Windows Python/浏览器交互、三套依赖导入及离线解包、模型真实加载/推理、4090 显存峰值、复杂海报质量。当前环境无法代替目标 4090 的实机验收。生成式标题需要界面手动确认，不自动生成用户图片。
