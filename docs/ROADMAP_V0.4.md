# V0.4 编辑能力修复计划

状态：计划已整理，以下编辑功能尚未开发，不修改用户当前 V0.3 安装包。

## P0：修复提取蒙版擦除

已定位：前端橡皮使用 destination-out 清除透明度，buildLogo 却读取蒙版红色通道；后端 get_mask 也直接将 RGBA 转 L，未应用 alpha。透明像素的 RGB 可能仍是白色，导致看似擦除后又出现，或提交结果与预览不一致。

统一蒙版契约：编辑器以内存 alpha 表示选区；提交前显式导出黑底白字灰度图，服务端转换遵循相同规则。兼容历史灰度蒙版，避免旧任务被解释成全选。

- 修补蒙版与标题提取蒙版分别提供添加/擦除工具。
- 外部透明 Logo 的像素编辑使用独立 alpha，不在擦除时切换成原图提取。
- 增加透明棋盘格、笔刷轮廓、撤销/重做与“仅重置当前蒙版”。
- 验收：阈值提取后擦除笔画，预览、提交、重开任务、导出均不恢复；外部 Logo 同样有效。

## P0：删除图片与任务

- 左侧任务条目增加删除按钮；任务中心支持批量删除。
- 默认进入回收站，可恢复；只有管理员可永久清理，同时显示将释放的占用空间。
- 排队任务先撤出队列；运行中任务等待安全取消完成后再删除，不边处理边删文件。
- 移入回收站保留原图、参数和历史版本，但从正常列表与导出中排除。
- 永久删除仅处理程序 data 中属于该任务的文件，不删除上传来源/NAS 素材，也不删除共享模型。
- 使用版本检查，处理多人同时编辑、删除与导出的竞争。
- 验收：单删、批删、恢复、永久清理、重启后状态、多用户冲突均可核对。

## P1：整图缩放与裁切

分开实现两种交互：编辑视图缩放/平移（不改变图片），输出构图缩放/平移/裁切（影响成品）。

- 视图支持滚轮缩放、拖动平移、适合窗口与 100%。坐标由视图逆变换映射回规范化原图，保持画笔、检测框和蒙版对齐。
- 输出画布支持“完整适应 / 铺满裁切 / 自由裁切”、锁定目标比例、拖动位置、缩放滑块及重置。
- 人物/背景层与标题层分别调整，画布外区域以暗色遮罩提示；不会自动拉伸变形。
- 默认不覆盖原图；每版保存变换参数。现有后端 crop 字段只能作基础，不能视为已完成交互。
- 验收：不同纵横比、缩放后画笔、裁切与 Logo 安全边距、重开任务、预览和导出一致。
